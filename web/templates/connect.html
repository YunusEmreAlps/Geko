What this check observes

Checks use one sample from the latest committed OTLP export per namespace, service and environment, kept in memory for up to five minutes. Imports and old stored traces are excluded. A newer sample can replace an earlier one; versions and run IDs are representative, not exhaustive. Token selection configures the snippets, not proof of which credential exported a sample.

Need to instrument your application?
Go
Add the SDK and an OTLP exporter in code. See examples/go in the Geko repository.
Node.js
npm install @opentelemetry/api @opentelemetry/auto-instrumentations-node
node --require @opentelemetry/auto-instrumentations-node/register app.js
Python
pip install opentelemetry-distro opentelemetry-exporter-otlp
opentelemetry-bootstrap -a install
opentelemetry-instrument python app.py
Java
java -javaagent:opentelemetry-javaagent.jar -jar app.jar
.NET
Install OpenTelemetry .NET Automatic Instrumentation, or add the SDK with the OTLP exporter.

More languages: OpenTelemetry zero-code instrumentation.
